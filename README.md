# จดเงิน: แอพรายรับรายจ่าย

เว็บแอพจดรายรับรายจ่าย ใช้ฟรีโดยไม่ต้องมีบัญชี Claude ข้อมูลเก็บอยู่ในเครื่องของผู้ใช้แต่ละคน ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ ไม่มีเน็ตก็ใช้ได้ และเพิ่มไว้ที่หน้าจอโฮมให้เปิดเหมือนแอพได้

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอพ |
| manifest.webmanifest | ชื่อ ไอคอน และสีของแอพตอนเพิ่มที่หน้าจอโฮม |
| sw.js | ทำให้เปิดแอพได้ตอนไม่มีเน็ต |
| icon-192.png, icon-512.png, icon-maskable-512.png | ไอคอนแอพ (Android) |
| apple-touch-icon.png | ไอคอนแอพ (iPhone) |
| favicon-32.png | ไอคอนบนแท็บเบราว์เซอร์ |

## เอาขึ้นเว็บด้วยมือถือ (GitHub Pages ฟรี)

1. แตกไฟล์ zip ก่อน: iPhone เปิดแอพ "ไฟล์" แล้วแตะไฟล์ zip / Android เปิด "Files by Google" แล้วแตะ "แตกไฟล์"
2. เข้า github.com ด้วย Safari หรือ Chrome แล้วล็อกอิน (ยังไม่มีบัญชีก็สมัครฟรี)
3. แตะปุ่ม + มุมขวาบน → New repository → ตั้งชื่อ `jodngern` → เลือก Public → Create repository
4. ในหน้า repo ที่เพิ่งสร้าง แตะลิงก์ "uploading an existing file" → Choose your files → เลือกไฟล์ทั้ง 9 ไฟล์ในโฟลเดอร์ที่แตกไว้ → แตะ Commit changes
5. ไปที่ Settings → Pages → ตรง Branch เลือก `main` และ `/ (root)` → Save
6. รอ 1–2 นาที แล้วรีเฟรชหน้า Pages จะขึ้นลิงก์ประมาณ `https://ชื่อผู้ใช้.github.io/jodngern/`

ถ้าหน้า GitHub บนมือถือหาเมนูไม่เจอ ให้เปิด "ขอเว็บไซต์เดสก์ท็อป" ในเมนูของเบราว์เซอร์

## เพิ่มไว้ที่หน้าจอโฮม

- iPhone: เปิดลิงก์ใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- Android: เปิดลิงก์ใน Chrome → เมนู ⋮ → ติดตั้งแอพ (หรือ เพิ่มลงในหน้าจอหลัก)

## อัปเดตแอพทีหลัง

เข้า repo → Add file → Upload files → อัปโหลด index.html ตัวใหม่ทับของเดิม → Commit changes ผู้ใช้จะได้เวอร์ชันใหม่ตอนเปิดแอพครั้งถัดไป ข้อมูลที่จดไว้ยังอยู่ครบ

## เรื่องข้อมูลที่ควรรู้

- repo เป็น Public แต่ข้างในมีแค่โค้ด ข้อมูลรายรับรายจ่ายของแต่ละคนอยู่ในเครื่องของคนนั้น คนอื่นที่เปิดลิงก์เดียวกันจะไม่เห็นข้อมูลของคุณ
- ถ้าลบแอพ ล้างข้อมูลเบราว์เซอร์ หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ควรกด "สำรองข้อมูลทั้งหมด" ในแท็บเพิ่มเติมทุกเดือน (แอพจะเตือนเมื่อไม่ได้สำรองนานเกิน 30 วัน) แล้วนำไฟล์กลับเข้ามาได้ด้วยปุ่ม "เลือกไฟล์"
- ย้ายข้อมูลระหว่างเครื่องได้ด้วยไฟล์สำรองเดียวกัน
- อ่านสลิปบนเครื่องด้วยตัวอ่านตัวอักษรภาษาไทย ครั้งแรกต้องมีเน็ตเพื่อโหลดตัวอ่าน (ประมาณ 10–15 MB) แม่นน้อยกว่าให้ AI อ่าน ควรตรวจยอดก่อนบันทึก
- สั่งด้วยเสียงใช้ระบบฟังเสียงของเบราว์เซอร์ ใช้ได้ดีใน Chrome บน Android ส่วน iPhone ให้แตะช่องข้อความแล้วใช้ปุ่มไมค์บนคีย์บอร์ดแทน
- ถ้าเปิดไฟล์เดียวกันนี้ใน Claude แอพจะเก็บข้อมูลไว้ในบัญชี Claude และใช้ AI อ่านสลิปกับแยกข้อความเสียงให้เอง
